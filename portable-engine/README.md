# Portable Intelligence Engine

**BIG DATA ENERGY** — portable autonomous intelligence, local-first and EIE-governed.

This directory will contain the portable runtime as it separates from the Citizen's Record application.

## Design

The engine is general-purpose. Business automation is one workload, not the product definition.

Primary workload classes:

- document intelligence
- evidence research
- software engineering
- web research
- knowledge management
- automation
- business operations
- offline assistance

Every agent action should be observable and auditable. Every important claim should be traceable to evidence.

## Build order

1. filesystem connector + authorization boundary
2. document indexing/retrieval
3. evidence bundle + receipt interface
4. orchestrator
5. model provider abstraction
6. local model adapter
7. MCP tool adapter
8. specialist agents
9. autonomous task loop
10. portable packaging
